# 온라인 성균관 2030 🏮

> 혼자 공부하기 외로운 날, 600년 된 명륜당 마루에 같이 앉아요.
> 웹툰·한류&미래콘텐츠 최종과제 — 2030 미래콘텐츠 · 월드모델 파일럿

## 월드모델 구성
| 요소 | 내용 |
|---|---|
| 공간 | 명륜당(공부 마루 24자리) · 은행나무 두 그루 마당 · 동재/서재 · 종각 · 담장과 정문 |
| 에이전트 | 나 · 실제 접속자(실시간) · NPC 유생(스스로 공부하고 쉬고 수다) · 훈장님 AI(순찰, 격려, 질문 답변) |
| 이벤트 | 개인 향 타이머 · 매시 정각 공용 종(:00~:50 공부, :50~:00 쉬는 시간) · 향을 다 태우면 등불 점등 |
| 세계 변화 | 기본은 지금 실제 한국 계절·시각 / 프롬프트로 계절·시간·날씨 변경(방 전체 10분) / 모두의 공부량만큼 등불 40개가 켜짐 |

## 기능
- 🪷 빈 방석에 앉기 → 오늘의 목표 + 향 길이(25·50·90·직접) 또는 "정각 종에 맞추기"
- 🪔 향이 실제로 타들어가고 연기가 남, 다른 사람 머리 위엔 목표와 남은 시간
- 🌙 집중 모드: 내 눈으로 책상을 보는 시점 + 화면을 초당 4번만 그려 배터리 절약
- 다른 탭에서 공부해도 타이머·종은 계속 흐르고, 탭 제목에 남은 시간 표시
- 🍵 쉬는 시간에만 대화 / 훈장님 곁에 가면 "여쭙기"
- 📜 일과 두루마리: 오늘 피운 향 기록 + 훈장님 한 줄 평 → 이미지 저장
- 🍂 계절·날씨 프롬프트 (OpenAI 없으면 키워드 규칙으로 동작)

## 배포 (사주포차와 같은 방법)
1. 이 폴더 내용을 새 GitHub 저장소에 올림 (`node_modules`, `dist` 제외)
2. Vercel → Add New Project → 저장소 선택 (Vite 자동 인식)
3. Environment Variables: `OPENAI_API_KEY`, `OPENAI_MODEL`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
   - Supabase는 사주포차 프로젝트 것을 그대로 써도 됨 (새 테이블 필요 없음, Realtime만 사용)
4. Deploy → 공유는 `프로젝트명.vercel.app` 주소로

## 조작
WASD/방향키 이동 · Shift 달리기 · 드래그 시점 · 휠 줌 · E/Space 앉기·여쭙기 · 모바일은 조이스틱

## 개인정보
공부 기록은 브라우저(localStorage)에만 저장. 다른 사람에겐 이름·옷·목표·남은 시간·오늘 등불 수만 공유.

## 파일
- `src/scene.js` 성균관 공간·계절·날씨·등불 / `src/main.js` 흐름 / `src/player.js` 캐릭터·카메라
- `src/net.js` 멀티플레이·공용 종·NPC 유생 / `src/ai.js` 훈장님·계절 프롬프트(오프라인 대체 포함)
- `api/hunjang.js`, `api/theme.js` Vercel 서버 함수(OpenAI)
